# Трассировка варианта №26

## Заполнение, выбивание и повторный выбор

Трасса задана вручную и показывает работу дисциплин. Два источника И1 и И2, два прибора П1 и П2, три ячейки. Для согласованности с ИЗ2 можно взять a = 1, b = 4 условных единиц времени у обоих источников. Приборы используют ПЗ1 с общим μ > 0. Моменты завершения ниже соответствуют условным длительностям обслуживания. Счётчик постановок начинается с 0. Запись `A#1` означает заявку A с номером постановки 1.

Если в момент 5 уже обработано завершение B, таблица календаря содержит следующие события. Строки отсортированы по ключу календаря. В момент 5,5 обрабатывается последняя разрешённая генерация И1, после чего плановая генерация И2 в 6,5 отменяется.

Суммарная занятость П1 составляет 8 единиц времени, П2 также 8, поэтому оба коэффициента равны 0,8. Ожидание F составило 6 − 4 = 2, обслуживание 7 − 6 = 1, пребывание 3.

## Краевой случай Д1ОО4

Пусть оба прибора заняты, буфер содержит `[—, Y#10, Z#9]`, а УБ = 3. После постановки X буфер имеет вид `[X#11, Y#10, Z#9]`. При следующем приходе по Д1ОО4 выбивается X#11 из **ячейки 1**. Это последняя постановка среди занятых ячеек. УБ остаётся на позиции 3, и при ближайшем назначении поиск заявки начнётся с Z#9.
