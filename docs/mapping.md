# Маппинг

## Обработка телеметрии датчиков

Жирнов М. С., группа 5130904/40101. Вариант №26.

`ИБ — ИЗ2 — ПЗ1 — Д1ОЗ3 — Д1ОО4 — Д2П2 — Д2Б3 — ОР1 — ОД2`

| Элемент СМО | Сущность бизнес-домена | Назначение |
| --- | --- | --- |
| Источник | Датчик оборудования | Формирует неограниченный поток измерений. Интервалы между сообщениями равномерно распределены на заданном отрезке (ИБ, ИЗ2). |
| Заявка | Сообщение с измерением | Содержит идентификатор датчика, номер сообщения, время генерации, тип параметра и его значение. Требует обработки вычислительным узлом. |
| Буферная память | Массив ожидающих сообщений ограниченной вместимости | Хранит сообщения до начала обработки. Новая заявка занимает первое от начала свободное место. Остальные заявки не сдвигаются (Д1ОЗ3). |
| Прибор | Вычислительный узел сервера | Обрабатывает одно сообщение за раз. Время обслуживания имеет экспоненциальное распределение (ПЗ1). |
| Диспетчер постановки | Приёмщик телеметрии | Помещает сообщение в первое свободное место буфера. При переполнении удаляет последнюю из уже поступивших в буфер заявок и записывает новую на её место (Д1ОЗ3, Д1ОО4). |
| Диспетчер выбора | Планировщик обработки сообщений | Выбирает свободный узел по кольцу (Д2П2), затем сообщение из буфера по кольцу (Д2Б3). Использует два независимых указателя и после выбора перемещает каждый на следующую позицию. |
| Отказ | Потеря ожидающего измерения | При занятости всех приборов и заполненном буфере вытесняется последняя поступившая в буфер заявка. Её отказ учитывается в статистике соответствующего датчика (Д1ОО4). |
| Обслуживание | Проверка и сохранение измерения | Узел проверяет формат сообщения, преобразует значения и записывает результат в хранилище. До завершения обработки узел занят. |
| Выход из системы | Сохранённое либо отклонённое измерение | После завершения обслуживания сообщение покидает систему как обработанное. При вытеснении из буфера оно покидает систему с отказом. Передача из буфера на прибор выходом из системы не является. |
